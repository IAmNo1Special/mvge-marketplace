# eval-bridge

Evaluation harness and RL data exporter for MvgeOS, compatible with google/adk-python evalsets.

## Features
- **Evaluation Harness**: Automated evaluation of agent runs against standardized tasks.
- **RL Data Exporter**: Exports trajectory data in format compatible with reinforcement learning pipelines.
- **Reproducible Scoring**: Calculates execution metrics and pass rates across agent variants.

# submvge-bridge

Kernel sub-Mvge summoning, persistent sub-sessions, and reactive wakeup bridge for Mvge.

## Features
- **Sub-Agent Delegation**: Summons isolated sub-agents with dedicated workspaces and scoped tools.
- **Tome Persistence**: Manages child Tomes linked to parent session trees.
- **Reactive Wakeup**: Coordinates background task completion and reactive notification delivery.
